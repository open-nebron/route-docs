# OpenAPI 3.1 & Swagger UI (`/docs`)

Interactive Swagger UI serving the OpenAPI 3.1 specification for the `core-api` microservice.

---

## Route Overview

- **Method**: `GET`
- **Path**: `/docs`
- **Authentication**: None (Public)
- **Service**: `core-api` (Port: `4002`)

---

## Usage

Navigate to `http://localhost:4002/docs` in your browser to inspect interactive API schema documentation, test endpoints, and view payload models.
